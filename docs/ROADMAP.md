# Plán rozvoje

Plán rozvoje se vede v **GitHub Issues** - každý nápad, bug nebo úkol je samostatný issue. Kdokoli s GitHub účtem může otevřít nový issue nebo komentovat existující.

- **Aktuální plán + nápady:** [github.com/filipaldi/brnosaires/issues](https://github.com/filipaldi/brnosaires/issues)
- **Nový nápad / bug:** [otevřít issue](https://github.com/filipaldi/brnosaires/issues/new)

Hotové věci žijí v git historii a v zavřených issues - žádný samostatný changelog se tady nedrží.
